# tw-stock-screener 台股熱門標的分析工具

每個交易日收盤後，自動抓取台股上市櫃行情與三大法人買賣超，累積成歷史資料，
之後依「量、價、法人籌碼、技術指標」算出熱度分數並排行。

> 熱度高代表「有資金在買」，不代表一定會漲。本工具只用來縮小研究範圍，不構成投資建議。

## 資料來源

| 資料 | 上市 | 上櫃 |
| --- | --- | --- |
| 每日行情 | 證交所 MI_INDEX | 櫃買中心 dailyQuotes |
| 三大法人 | 證交所 T86 | 櫃買中心 insti/dailyTrade |
| 融資融券（選用） | 證交所 MI_MARGN | 櫃買中心 margin/balance |
| 集保股權分散（選用，每週） | 集保結算所 opendata 1-5（只有最新一週，從 2026-10-30 起累積） | 同左 |
| 產業別 | 證交所 OpenAPI t187ap03_L | 櫃買中心 OpenAPI mopsfin_t187ap03_O |

每次請求間隔 3 秒，避免被交易所封鎖。融資融券、集保是「選用資料」：抓不到不會讓每日排程失敗，下次執行會自動補最近 5 天。

## 在自己電腦上執行

```bash
pip install -r requirements.txt
python -m screener backfill --days 120   # 第一次：回補最近 120 個交易日（約 30–40 分鐘）
python -m screener fetch                 # 之後每天：抓今天
python -m screener status                # 看存了多少資料
python -m screener dashboard             # 產生 dashboard/index.html，點兩下用瀏覽器打開
pytest                                   # 跑測試
```

## GitHub Actions 自動執行

`.github/workflows/daily.yml` 會在週一到週五台灣時間 16:40 自動執行，
抓完的資料會自動 commit 回這個 repo。

第一次使用：到 repo 的 **Actions** 分頁 → 選「每日抓取台股資料」→ **Run workflow**，
`backfill_days` 填 `120`，就會回補歷史資料。

## 回補很久以前的歷史資料

`.github/workflows/history.yml`：到 **Actions** → 「回補歷史資料（依年份）」→ **Run workflow**，
填起訖年份（最早 2004）。每一年依序跑一次，打包成 `history-YYYY.zip` 放到 repo 的 **Releases → history**，
不放進 `data` 資料夾，以免 repo 太大。

各資料最早的日期（2026-11 實測）：上市股價 2004 年初、上市融資融券 2001-01-02、上櫃融資融券 2007-01-02、
上櫃股價 2007-04-23、上市三大法人 2012-05-02、上櫃三大法人 2014-12-01。早於這些日期的不會去抓，也不算缺資料。
重跑某一年時會先載入 Releases 裡已有的檔案，只補缺的部分（也會順便補上融資融券）。

## 權值股儀表板

`dashboard/index.html` 列出 `config.yaml` 裡 `watchlist` 設定的股票（自己的 ETF、自選股、上市市值前 50 大），
可切換日／週／月 K，顯示均線、MACD、RSI、KD、布林通道，並標出買點▲／賣點▼訊號，
附上每個訊號在這檔股票與整個股票池過去的平均報酬與上漲比例。

每檔股票最上方有一個**操作建議**：買進／加碼／賣出一半／全部賣出（下一個交易日開盤執行）、續抱、空手，並列出要盯的價位。

**預設是高勝率模式（`trading.mode: winrate`）**，不使用下面任何條件：

- **買進**：收盤在季線（60 日均線）之上，而且 RSI(3) < 25（多頭裡的短線急跌）
- **賣出**：RSI(3) > 70（反彈到短線過熱），或持有滿 20 個交易日（時間停損）；不設價格停損
- 用 2023–2025 年 54 檔權值股的歷史資料找出來（扣手續費與證交稅後）：2023–24 年勝率 65%；沒參與挑選的 2025 年 70%、2026 年 81%；0050 合計 19 筆賺 15 筆
- 勝率高不代表每筆都賺：贏的多半是小賺，偶爾一筆會虧 10–20%（2025 年最差一筆 −21%）

所有做法的回測報酬都已扣除手續費 0.1425%（買賣各一次）與證交稅（股票 0.3%、ETF 0.1%）。股價遇到拆股／合併（例如 0050 在 2025 年 1 拆 4）會自動還原。

其他做法也可以在 `config.yaml` 的 `trading.mode` 選：

| mode | 做法 | 規則 |
| --- | --- | --- |
| `winrate`（預設） | 高勝率 | 見上方 |
| `all_in` | 全進全出 | 底部確認就買；區域高點（KD 高檔死叉／RSI 超買回落）、跌破 10 日線、停損 −8% 任一成立就全部賣出 |
| `scale` | 低點加倉、高點賣一半 | 底部確認或多頭回檔再轉強就買／加碼 1 份（加上這 1 份不超過 3 份）；區域高點賣一半（持有份數也減半，例如 3 → 1.5）；跌破 10 日線或停損就全部賣出 |
| `auto`（預設） | 依牛熊切換 | 牛市用 `scale`，熊市、盤整、資料不足用 `all_in` |

- **底部確認**：近 5 日出現過任一種買點 ▲，而且今天 K 值在 D 值之上、收盤站上 5 日線；賣出之後要出現新的底部訊號才會再買
- **牛熊**：用 `trading.regime_from`（預設 0050）的年線判斷：收盤在年線上且年線上揚＝牛市，在年線下且年線下彎＝熊市，其他＝盤整；資料不滿 260 天＝資料不足
- **均線**：10 日線在月線之上＝多頭（上漲還沒結束），10 日線在月線之下＝空頭（下跌還沒結束）
  - `ma_entry_filter: true`（預設開）：買進／加碼還要 10 日線止跌（比 3 天前高），下跌告一段落才買
  - `ma_hold_in_uptrend: false`（預設關）：開啟後 10 日線在月線之上時區域高點不賣，10 日線跌破月線後區域高點恢復照賣；跌破 10 日線、停損照賣
  - 5／10 日、10 日／月線、月線／季線的交叉列在訊號表做參考統計，不算進底部訊號
- 訊號用收盤判斷、隔天開盤成交。圖上標「買／加／賣½／清」，下方交易紀錄會同時列出三種做法的成績與「一直抱著」比較

下面另有**趨勢強弱**（強多／偏多／中性／偏空／強空），是 6 個狀態條件（月線、季線、月線方向、MACD、KD、RSI）各 ±1，
加減近 5 日買賣點訊號，總分 −8～+8。它描述「現在的狀態」，會比轉折慢，只當參考，不拿來決定買賣。

## 桌面分析工具

第一次使用要建立 Python 3.12 環境（不影響原本的 anaconda）：

```bash
C:naconda3\Scripts\conda.exe create -p .venv python=3.12 -y
.venv\python.exe -m pip install -r requirements-desktop.txt
```

之後點兩下專案裡的 **啟動分析工具.bat**（或 `.venv\python.exe -m screener app`）。

- **名單**：自選 ETF、市值前 50 大，加上「加入股票代號」加的股票；顯示價格、漲跌、操作建議、盤中試算
- **走勢圖**：K 線、月線、季線、高勝率規則的買（▲）賣（▼）點、RSI(3)、成交量；滾輪縮放、拖曳平移
- **盤中報價**：證交所即時報價，盤中（9:00–13:30）每分鐘自動更新。會試算「如果今天收在現價」會不會出現買賣訊號，以及收在多少會觸發
- **交易紀錄**：「下載交易紀錄範本」→ 用 Excel 填 → 「匯入交易紀錄」（也接受券商匯出、欄位為中文的 CSV／Excel）。會算持股、平均成本、損益（含手續費與證交稅），並逐筆跟規則比較
- **籌碼**：三大法人買賣超（每天）、融資融券餘額與券資比（每天）、集保千張大戶持股比例（每週）。建議框會整理成摘要，例如「外資連續賣超 20 天」「融資近 5 日 +11,837 張」
- **截圖**：用 Win+Shift+S 截圖後在視窗裡按 Ctrl+V，或把圖片拖進視窗；依股票與日期保存
- **資料**：讀專案的 `data/`，並自動加上 `../tw-stock-history/data` 的 2023–2025 年歷史；按「從 GitHub 更新資料」拉每日排程抓的新資料

個人資料（交易紀錄、截圖）存在 `mydata/`，不會推上 GitHub。

## 每支股票的最高勝率規則

```bash
python -m screener optimize                    # 2025-01-01 前挑規則、之後驗證
python -m screener optimize --split 2026-01-01 # 換切分日
```

每支股票在 240 組高勝率參數（均線條件 × RSI(2)/RSI(3) × 買進門檻 × 賣出門檻 × 最多持有天數）裡，
只用挑選期找勝率最高的一組（至少 8 筆、扣成本後平均賺錢），再用驗證期（沒看過的資料）跟共用規則比較。
驗證期勝率不低於共用規則、平均賺錢才標「適用」。結果在 `reports/per_stock_rules.md`（看）與 `.csv`（程式讀）。
資料有缺口會自動分段計算。目前只產生報表，儀表板仍用共用規則。
